# Security policy

## Supported versions

_classicborne_ is currently marked as unstable. On major version zero (0.x.x), only the latest minor version will be supported for patches.

## Reporting vulnerabilities

[Open a security advisory](https://github.com/BunnyNabbit/classicborne/security/advisories/new) on _GitHub_, or send an email to the maintainer. Email addresses can be found in the _Git_ history.
